# DefiLumen

DefiLumen implements a dynamic, distributed architecture for real-time processing, event-driven framework with scalable nodes and a central gateway.

DefiLumen is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/DefiLumen.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

DefiLumen is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
